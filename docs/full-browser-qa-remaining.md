## 頁面覆蓋核對

- 後台源碼目前 37 個 page.tsx；預覽、舊路由與 reset-password 也計入。逐項現況可用 `rg --files frontend/app/admin -g page.tsx` 核對。
- 公開源碼目前 14 個頁面路由模板；動態分類/文章/站點/住宿/隱私頁依實際配置與 fixture 準備測試實例。
- 需要完整確認的公開模板：首頁、分類列表/文章、聯絡、住宿列表/兩種詳情路由、站點首頁/動態頁、一般頁面列表/詳情、隱私列表/詳情、取消訂閱。
- 每頁至少確認載入、主要入口/表單、錯誤與空狀態，以及實際 CSS 桌機/平板/手機尺寸。首屏無溢出不能替代整頁視覺驗收。
- 目前尺寸覆寫與截圖比例不一致；以 innerWidth/innerHeight 與檢視後的實際圖片共同驗證，不能僅採要求尺寸或檔名當證據。

## 必須由人完成或當下確認

1. 新帳號/變更密碼/有效復原 token：使用者輸入新憑證與最終提交。
2. 角色或站點管理權限擴張：具體 UI 操作準備好後，當下確認。
3. 尚未測試的不可回復刪除：只限具名本次本地 QA 物件，當下確認。上一筆一般詢問的批准已使用。
4. 真實外部 SMTP/Email 客戶端：目前只有本地 JSONL transport，不能宣稱真實 Email 相容性已通過。
