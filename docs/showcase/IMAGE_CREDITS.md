# 展示網站圖片來源與授權

展示網站的品牌「慢域旅宿 Slowfield Stays」、旗艦民宿「禾境 Hejing Villa」、規劃中的「禾境·山嵐」「月霧山居」「礁岸之家」，以及其地址、電話、Email、LINE，**全部是虛構的**。網站上的每一張圖都是 AI 生成，不使用任何真實民宿或客戶的照片。

## AI 生成圖

- **提示詞與檔名**：`docs/showcase/AI_IMAGE_PROMPTS.md`
  - 第一批 14 張：景點、服務情境、規劃中民宿，已生成。
  - 第二批 25 張：禾境別墅本身。
- **檔案位置**：`素材/ai/<檔名>`（不進版控）。執行 `scripts/showcase/seed.mjs` 時會上傳到網站。
- **缺圖時**：對應的內容不上架，不會用不相符的圖代替。
- **授權**：依 OpenAI 使用條款，生成內容的權利歸使用者。對外公開前，請確認當時適用的條款與標示方式。
- **真實地名只是情境**：梅花湖、羅東夜市、羅莊櫻花步道等是真實地名，AI 圖是情境示意，不是實景照片。規劃中的民宿是概念圖，網站文案也寫明「規劃中」。
