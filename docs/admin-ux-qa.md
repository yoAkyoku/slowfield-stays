## 資料及環境邊界

`admin_ux_server.py` 僅監聽 127.0.0.1:8313，使用專案實際 FastAPI 路由、JWT、權限檢查與記憶體 SQLite；AsyncSessionFacade 使用既有測試轉接層。
自行建立兩站、三個角色、十二篇文章、四個標籤、首頁集合與橫幅。未複製正式站 DB、環境檔、個資；沒有 SMTP 寄送、正式上傳或部署。
程式明確覆寫測試環境與不可連線的預設 DB 地址，資料修改只開放測試登入、CMS 與站點設定路由；重啟即重建記憶體資料。
這驗證實際應用路由與儲存流程，不代表已驗證正式 PostgreSQL 部署環境。
