# 文章分類與網站頁面分離

## 操作入口

- 內容 → 文章分類：新增、改名、封存及還原分類；查看使用文章數及對應前台列表頁。
- 網站與頁面 → 網站頁面：新增一般頁面、編輯版面、設定收錄分類。
- 文章編輯：選擇文章分類；顯示預覽依網站頁面的實際收錄設定計算。

## 資料相容

分類存於站點 settings.article_categories；沒有這個欄位的舊站點，暫時從既有列表頁推導分類。首次分類寫入或網站設定保存會保留舊分類快照。一般網站設定保存不得直接新增、刪除或改名分类。

網站頁面仍存於 settings.pages。列表頁的 article_categories 是明確收錄來源，content_type 與 extra_content_types 保留相容；空陣列表示不收錄文章。分類封存不移除已发布文章與既有列表關聯。

新增頁面只建立頁面配置，不建立 CMS 文章或分類。新分類只建立分類，不建立網站頁面。前台多分類列表依文章ID去重。保留既有文章網址；自訂主分類使用既有 /page 詳情路徑並返回已配置的列表頁。

## 權限

分類查看/編輯分別使用 cms:read、cms:write，按目前網站隔離。列表收錄設定使用 site_users:write。一般頁面編輯仍沿用網站設定權限。公開資料只提供分類 label/status/sort_order，不公開後台QA欄位。
